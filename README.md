# Villain Syndicate

An original browser text RPG in the style of the old energy/stamina "villain empire"
games. It is a single HTML file with no build step: open `index.html` in a browser.

- **Schemes**: spend energy for cash and XP across five districts. Master all schemes
  in a district to take it over and win a loot item.
- **Fights**: spend stamina to fight rival villains. Your crew brings your best
  weapon, armor and vehicle for every member.
- **Heroes**: multi-hit boss fights that drop unique loot and come back stronger.
- **Arsenal, Crew, Lair**: buy gear, hire henchmen and buy properties that pay every minute.
- **Vault**: rivals raid the cash you carry, so bank it (for a fee).

Progress saves to the browser's localStorage.
